# Этап 4 — Типы SQL-инъекций

## Что делаем
Показываем разницу между основными техниками инъекций, которые умеет находить sqlmap,
и демонстрируем это на разных уровнях защиты DVWA (Low → Medium → High меняют способ фильтрации ввода).

## Теория (коротко, своими словами при заполнении)
- **Error-based** — ответ сервера содержит текст SQL-ошибки, из которого можно вытащить данные.
- **Boolean-based blind** — прямой ошибки не видно, но по разнице в ответе (true/false) можно восстанавливать данные бит за битом.
- **Time-based blind** — ни ошибки, ни видимой разницы в ответе нет, но можно намеренно замедлить SQL-запрос (`SLEEP()`) и по времени отклика делать выводы.

## Команды

Заставить sqlmap явно перебрать техники:
```bash
sqlmap -u "http://waf:8080/vulnerabilities/sqli/?id=1&Submit=Submit#" \
  --cookie="PHPSESSID=<вставить>; security=low" \
  --technique=BEUSTQ -v 3
```

Где:
- B — boolean-based blind
- E — error-based
- U — UNION query-based
- S — stacked queries
- T — time-based blind
- Q — inline queries

Повторить на **DVWA Security = Medium** — сравнить, что изменилось в запросе (там уже нет `id`
в чистом виде через GET, форма меняется на POST).

## Ожидаемый результат
- Понимание и демонстрация каждой техники на реальном ответе сервера
- Сравнение скорости: time-based заметно медленнее (несколько секунд на бит информации)
- Зафиксирована разница в поведении между Low и Medium уровнями DVWA
