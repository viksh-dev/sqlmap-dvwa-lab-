# WAF

WAF в этом проекте разворачивается через готовый образ `owasp/modsecurity-crs:nginx`
(см. `docker-compose.yml`, сервис `waf`) — он уже включает nginx + ModSecurity +
OWASP Core Rule Set, отдельно конфигурировать правила с нуля не нужно.

Эта папка — место для **кастомных правил**, если на Этапе 5 захочется показать
не только обход дефолтного CRS, но и написание/донастройку собственного правила
(например, специально ослабленного, чтобы продемонстрировать конкретный обход).

Чтобы подключить кастомные правила, нужно будет примонтировать эту папку в сервис `waf`
в `docker-compose.yml`, например:

```yaml
services:
  waf:
    volumes:
      - ./waf/custom-rules:/etc/modsecurity.d/owasp-crs/rules/custom
```

Это опционально — базовая версия проекта (Этап 5) прекрасно работает и с дефолтным CRS.
